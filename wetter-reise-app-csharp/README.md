# Wetter Reise App in C#

ASP.NET-Core-Razor-Pages-Webapp mit öffentlichen APIs:

- Open-Meteo Geocoding API für Stadtsuche
- Open-Meteo Forecast API für aktuelle Wetterdaten und 7-Tage-Prognose
- Wikipedia API für Touristenattraktionen in der Nähe

Die App braucht keinen API-Key und kann direkt mit .NET gestartet werden.

## Start

```powershell
dotnet run
```

Danach die angezeigte localhost-Adresse im Browser öffnen.
